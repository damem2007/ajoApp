# Archived Python UI reference

These HTML templates, browser controllers, old UI tests and rendering handlers are retained only as migration reference. They are outside Next.js public assets, outside the backend package and outside deployment builds; they are not executed by the application.

The supported sandbox uses the native Next.js TSX screens with FastAPI synthetic providers. The original Python domain prototype and its tests remain in backend/app/main.py and tests/test_platform.py. Current financial regressions use isolated temporary SQLite databases. No archived file contains database credentials or a database copy. assets.sha256 records the original asset contents.
